# لمسة باستيل — Pastel Touch

موقع تعريفي لمشروع **تزيين وتجديد المطابخ بالاستكرات** (دواليب، رخام، جدران، ثلاجة، ستائر وإكسسوارات) بألوان الباستيل.

## محتوى الموقع
- واجهة رئيسية مع زر طلب معاينة عبر واتساب
- سلايدر **قبل وبعد** تفاعلي (يشتغل باللمس على الجوال)
- الخدمات، المميزات، وخطوات العمل
- معرض أفكار مع فلتر حسب اللون
- نموذج طلب معاينة يرسل البيانات كرسالة واتساب

## التعديلات المهمة
| المطلوب | المكان |
|---|---|
| رقم الواتساب | `assets/js/main.js` ← `CONFIG.whatsapp` (الحالي: `966558118167`) |
| النصوص بين الأقواس مثل `[مدة التنفيذ]` و`[المدينة والأحياء]` | `index.html` |
| اللون الأساسي | `assets/css/style.css` ← `--accent` |
| الصور | مجلد `assets/img/` (يفضّل استبدالها بصور أعمالكم الفعلية) |

## التشغيل
موقع ثابت (HTML + CSS + JS) بدون أي أدوات بناء — افتح `index.html` مباشرة، أو انشره على GitHub Pages.
